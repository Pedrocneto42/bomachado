# Bom Achado Variedades(loja Ficticia)

Projeto de desenvolvimento de um site institucional
para uma loja de variedades.

## Objetivo

Apresentar a loja, seus produtos e disponibilizar
um canal de contato com os clientes.

## Tecnologias Usadas

- HTML5
- CSS3
- PHP
- Bootstrap 5
- MySQL
- Git e GitHub

## Funcionalidades

- Página inicial com carrossel.
- Catálogo de produtos.
- Informações sobre a loja.
- Formulário de contato.

## Autor

Desenvolvido como projeto de aprendizagem para a materia de projeto integrador  e WEB3 do Curso Tecnico em informatica do IFSUL de  minas.
